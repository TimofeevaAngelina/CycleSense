# CycleSense

CycleSense — Android-приложение для отслеживания менструального цикла, анализа психофизиологического состояния и краткосрочного прогнозирования показателей самочувствия с использованием машинного обучения.

Приложение объединяет календарь цикла, дневные записи, физиологические данные из Health Connect, локальную аналитику и прогнозирование на основе TensorFlow Lite-моделей.

## Основные возможности

- создание и настройка пользовательского профиля;
- авторизация через Google-аккаунт;
- облачное резервное копирование и восстановление данных;
- ведение календаря менструального цикла;
- отметка фактических дней менструации;
- ввод дневных оценок самочувствия;
- получение данных о шагах, сне и частоте сердечных сокращений через Health Connect;
- расчет ориентировочных энергозатрат;
- отображение фаз цикла и прогнозных отметок;
- построение прогноза напряжения, энергии, настроения, концентрации и дискомфорта на ближайшие три дня;
- отображение аналитики по фазам цикла;
- анализ динамики субъективных и физиологических показателей;
- анализ взаимосвязей между показателями;
- демонстрационный режим с синтетическими данными;
- локальное хранение данных в Room;
- локальный запуск моделей машинного обучения на устройстве;
- экран подписки и тестовая активация премиум-доступа.

## Модели машинного обучения

Для прогнозирования используются GRU-модели, обученные на синтетическом дневном датасете.

Каждая модель прогнозирует один показатель на ближайшие три дня:

- напряжение;
- энергия;
- настроение;
- концентрация;
- дискомфорт.

Модели конвертированы в формат TensorFlow Lite и запускаются локально на устройстве.

Входные признаки включают календарные характеристики цикла, фазу, шаги, сон, частоту сердечных сокращений, расчетные калории и историю субъективных оценок.

## Структура приложения

- Начальный экран — выбор основного режима или демонстрационного режима.
- Google-авторизация — вход в основной пользовательский профиль через Google-аккаунт.
- Онбординг — создание профиля и ввод исходных параметров.
- Календарь — просмотр дней цикла, фаз, дневных записей и прогнозных отметок.
- Диалог дневной записи — ввод субъективных оценок самочувствия.
- Прогноз — отображение значений пяти показателей на ближайшие три дня.
- Аналитика — фазовая аналитика, динамика показателей и анализ взаимосвязей.
- Профиль — параметры пользователя, Health Connect, документы приватности и управление аккаунтом.
- Облачное резервное копирование — сохранение и восстановление пользовательских данных при наличии авторизации.
- Подписка — экран премиум-доступа и тестовая активация подписки в прототипе.
- Демонстрационный режим — работа с синтетическими профилями и тестовыми данными.

## Установка приложения

1. Клонируйте репозиторий:

```bash
git clone https://github.com/TimofeevaAngelina/CycleSense.git
```

2. Откройте проект в Android Studio.

3. Добавьте файл `google-services.json` в папку:

```text
app/
```

4. Синхронизируйте Gradle-проект.

5. Запустите приложение на Android-устройстве или эмуляторе.

Для работы с физиологическими данными требуется установленный и доступный Health Connect.

## Приватность

CycleSense работает с чувствительными пользовательскими данными, поэтому в приложении предусмотрены:

- локальное хранение основной истории;
- локальный инференс TensorFlow Lite-моделей;
- запрос только необходимых разрешений Health Connect;
- разделение основного и демонстрационного режимов;
- исключение смешивания реальных и синтетических данных;
- отключение автоматического резервного копирования локальных данных Android;
- документы о конфиденциальности и условиях использования.

Приложение не является медицинским сервисом. Прогнозы и аналитика предназначены только для самонаблюдения и не заменяют консультацию специалиста.

## Инструкция пользователя

1. Запустите приложение и выберите основной или демонстрационный режим.
2. В основном режиме выполните вход через Google-аккаунт.
3. Создайте профиль и укажите исходные параметры цикла.
4. Откройте календарь и выберите нужную дату.
5. Заполните дневную запись: напряжение, энергию, настроение, концентрацию и дискомфорт.
6. Подключите Health Connect для получения данных о шагах, сне и частоте сердечных сокращений.
7. Постройте прогноз на ближайшие три дня.
8. Перейдите во вкладку аналитики для просмотра фазовой динамики, графиков и взаимосвязей.
9. Используйте демонстрационный режим для проверки функций приложения на синтетических данных.
